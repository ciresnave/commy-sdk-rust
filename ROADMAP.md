# Roadmap (SDK lane)

Authoritative portfolio priorities live in the portfolio roadmap; this file records what is specific to this repository.

| # | item | state | note |
|---|---|---|---|
| 5.1g | The 5 `#[ignore]` integration tests (`tests/integration_examples.rs`): `test_server_startup`, `test_client_connection`, `test_client_authentication`, `test_basic_client_example_pattern`, `test_multiple_clients` | open | They need a running Commy server. `CommyServer::prepare` looks for a pre-built `target/release/commy` (or `target/debug/commy`) relative to the working directory, copies it, and writes **placeholder TLS files** (`generate_self_signed_cert` writes fake PEM text), then starts it on 127.0.0.1:8443 with `COMMY_*` env vars. Run them on the self-hosted runner with the same conditions as the other repos' ignored tests: built Commy binary at that path, a real self-signed certificate, port 8443 free, no `#[ignore]` gate (select by job, e.g. `cargo test --test integration_examples -- --include-ignored`). Replace the placeholder certificate generation with a real self-signed one first (a server given fake PEM text is expected to fail its TLS setup; this has not been tried yet, so it is UNVERIFIED which of the 5 tests would pass today). |
| audit-2 | Operations run unauthenticated: only `create/get/delete_service` check authentication; `create_tenant`, `delete_tenant`, `read/write_variable`, `subscribe`, `unsubscribe`, `heartbeat` do not (and the server does not check either) | open | Needs server enforcement plus an `Authenticated<Client>` typestate (breaking). |
| audit-3 | Replies are matched to requests only by arrival order; `write_variable`/`subscribe`/`unsubscribe` never read their reply, so the next call consumes a stale one | open | Needs `request_id` on every request echoed in the reply (wire contract with Commy). |
| audit-4 | Wire disagreements with the server: `api_key` vs `key`, error-code spelling | open | Shared wire-types crate (`commy-wire`) with golden vectors. |
| S1-S8 | Local zero-copy shared-memory byte sharing per the approved Commy plan | in progress | S8 done (0.2.4: deps refreshed, repo URL fixed, "complete"/"production-ready" claims removed, stray logs and `Cargo.toml.orig` dropped). S1 file-open + nonce read + fallback and the S2 SDK-only alias are in `src/local_map.rs` (0.2.3). The handshake (`Client::negotiate_local`, commy-wire 0.2.1) is in 0.3.0. Still to do: wiring local mode into Service, S3-S7. |
